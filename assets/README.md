## Usage Guidelines

### In Presentations
1. Reference images using relative paths: `presentation_assets/filename.ext`
2. Use appropriate logo variant based on slide background (dark/light)
3. Compress large images if file size becomes an issue
4. Maintain aspect ratios when displaying screenshots

### Brand Consistency
- Follow brand colors: Primary (#0E58FF), Highlight (#FF7462), Marker (#FFC700)
- Use Inter font family for text overlays
- Maintain consistent spacing and alignment with brand guidelines

### File Formats
- **PNG**: Product screenshots, icons (transparency support)
- **JPG**: Photos, backgrounds (smaller file sizes)
- **SVG**: Logos, scalable graphics (infinite scaling)
- **PDF**: Reference documents, brand guidelines

## Adding New Assets

When adding new presentation assets:
1. Use descriptive, lowercase, hyphenated filenames
2. Optimize images for web (compress without quality loss)
3. Add entry to this README with description and file size
4. Update relevant sections in `claude.md` if needed
5. Consider both light and dark background compatibility
